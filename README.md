# 一点一点 · 数学方法：从具体问题到模型与证明

当前开放：**算法分析 → 时间复杂度／操作序列成本 → 摊还分析**专题，共四课。势能法是摊还分析的一种证明方法；动态数组是一种数据结构，在这里作为分析案例。

面向学过本科离散数学和微积分、希望恢复数学推理能力的学习者。课程训练从具体问题建立模型、说明假设、完成证明，并检验适用范围。当前专题以动态数组为对象，练习成本定义、求和、不变量和势能证明。后续方向均标记为待安排，不呈现为空的已开放课程。

## 学科定位与路线

建议复习顺序：离散数学的计数与证明 → 求和、递推与渐近分析 → 算法分析中的摊还分析 → 概率与期望。这个顺序服务于学习安排，不意味着每个主题都是下一个主题的严格先修。数值分析是近似、误差和稳定性的独立后续方向。

只有摊还分析专题已制作。其他主题在页面中明确标为待制作，没有空课程入口。本专题实际需要基本代数、等比求和和 O／Θ 记号；不要求概率论，也不要求先解复杂递推。

## 导航与学习顺序

先阅读学习路线与专题定位，再按“聚合分析 → 记账法 → 势能法 → 扩缩容策略”学习。桌面使用可折叠的多层侧栏（算法分析 → 摊还分析 → 四课），手机通过“课程目录”打开同样的目录。折叠状态同步，面包屑显示当前课的位置。一次只显示概览或一节课，支持 `#aggregate`、`#banker`、`#potential`、`#hysteresis` 深链接及浏览器前进／后退。切课保留当前实验数据并暂停自动播放。

第一课先介绍动态数组、元素数 n、容量 C 和成本单位，再进入实验。每课开头说明与上一课的关系，结尾提供下一课入口。

## 四节课

1. **聚合分析**：运行翻倍扩容的动态数组，观察成本尖峰，用几何级数证明从空数组开始的 m 次追加总成本小于 3m（m ≥ 1）。
2. **记账法**：每次收取 3 点信用，逐前缀核对收入、实际成本和余额；区分有限实验与非负余额证明。
3. **势能法**：用 Φ(n,C)=2n−C 计算每步摊还成本，单独处理首次分配，推导望远镜求和。说明每次收 3 的记账余额在 m ≥ 1 时等于 Φ+1。
4. **扩缩容滞回**：比较半满缩容与四分之一满缩容，在相同的删除／追加序列下观察容量抖动与真实总成本。

每节配有计算或证明判断练习、解释和重试。最后讨论固定增量扩容为何产生平方级总复制成本。

## 成本模型

追加写入计 1，复制每个旧元素计 1；不计内存申请、释放和其他固定开销。初始元素数与容量为 0，首次容量为 1，之后写满时翻倍。

扩缩容实验从 n=9、C=16 开始，删除末尾元素计 1，并计入缩容时复制剩余元素的成本。容量最小为 2，每次删除最多缩容一次。阈值条件包含等号。

## 使用与无障碍

学习进度只保存在当前浏览器，可以清除；实验状态刷新后重置。没有数据上传、分析追踪或外部接口调用。

控制按钮支持触屏和键盘。图表来自实际算法记录，槽位与费用同时有文字描述。自动播放需要主动开启，可暂停；隐藏标签页会停止播放。减少动态效果偏好会关闭过渡。
