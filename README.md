# 一点一点 · 本科数学互动课程

主线为线性代数、微积分与概率论，共九课。面向学过本科数学、希望恢复概念理解和推导能力的学习者。通过可操作图形观察数学对象，再阅读定义与推导，完成带解释的练习。算法分析的四节课保留为选学应用。

## 数学课程

### 线性代数：向量、坐标与线性结构

1. 线性变换与矩阵：改变矩阵的列，观察基向量、网格与有向面积。
2. 基与坐标变换：求同一向量在不同基下的坐标，检查基退化时的无解或多解。
3. 特征方向与迭代：计算实对称矩阵的特征值，观察反复变换的方向变化与边界情况。

先修：向量坐标、二元一次方程。深链接：`#linear-map`、`#linear-basis`、`#linear-eigen`。

### 微积分：局部变化与整体累积

1. 导数与局部线性近似：比较函数增量与一阶近似，量化误差。
2. 梯度与方向导数：在二元函数上改变单位方向，计算方向导数。
3. 积分与累积量：比较左端点、右端点和中点黎曼和，联系原函数与定积分。

先修：函数、极限；梯度课使用向量与点积。深链接：`#calculus-local`、`#calculus-gradient`、`#calculus-integral`。

### 概率论：分布、平均与波动

1. 随机变量与分布：从样本结果到数值，再合并相同取值的概率。
2. 期望与线性性：使用联合分布计算期望，检验依赖关系对期望之和的影响。
3. 方差与独立性：计算方差和协方差，说明方差相加的条件。

先修：有限求和与基本概率。本组使用离散分布，可以独立学习。深链接：`#probability-distribution`、`#probability-expectation`、`#probability-variance`。

## 选学应用：摊还分析

算法分析 → 时间复杂度 → 摊还分析。四课依次为聚合分析、记账法、势能法与扩缩容策略。动态数组是分析实例；每写入或复制一个元素计一次基本操作。内存申请、释放等固定开销在模型中省略。初始数组为空，首次容量为 1，写满后翻倍。扩缩容实验从 n=9、C=16 开始，删除计 1，缩容另计复制次数；容量最小为 2。

原有 `#aggregate`、`#banker`、`#potential`、`#hysteresis` 深链接保持可用。需要等比求和与 O／Θ 记号。

## 学习与导航

首页先展示三个数学单元与先修知识。桌面侧栏和手机目录按学科折叠；每次显示一节课，支持深链接、浏览器前进与后退。切课保留当前实验数据；刷新页面重置实验。有限个图形示例用于观察，推导说明一般结论成立的条件。

组合计数、递推与渐近分析、数值分析为待制作方向，无空课程入口。

## 本地运行

建议使用 Node.js 24。

```sh
npm ci
npm run dev
```

访问终端显示的地址下的 `/math/`。构建与预览：

```sh
npm run check:js
npm run build
npm run preview
```

## 发布

仓库：`Yikai-Liao/math`。部署地址：<https://yikai-liao.github.io/math/>。

GitHub Pages 发布来源设为 **GitHub Actions**。推送到 `main` 后，官方 Astro 与 Pages 工作流构建并发布 `dist`。Astro 配置了 `/math` 基路径；脚本和样式由 Vite 生成带内容哈希的文件，避免新页面误用旧交互代码。

## 使用与无障碍

学习进度只保存在当前浏览器，可以清除；实验状态刷新后重置。没有数据上传、分析追踪或外部接口调用。

控制按钮支持触屏和键盘。图形由当前数学参数或操作记录计算生成，关键结果同时提供文字说明。自动播放需要主动开启，可暂停；隐藏标签页会停止播放。减少动态效果偏好会关闭过渡。

## 项目结构

- `src/pages/index.astro`：学习路线、已有算法课与数学组件集成
- `src/components/*Lessons.astro`：三个数学单元的正文、实验与练习
- `src/components/CourseNav.astro`、`src/data/curriculum.js`：共享课程目录
- `src/scripts/{linear,calculus,probability}.js`：各数学单元的模型与交互
- `src/scripts/course.js`：路由、算法实验与其学习进度
- `src/styles/{course,mathematics}.css`：响应式布局
- `astro.config.mjs`：静态构建及 Pages 路径
- `AGENTS.md`、`SKILLS.md`：课程规范与技能许可

历史测试记录只覆盖其标明的版本；新增数学单元的验证应单独记录。
